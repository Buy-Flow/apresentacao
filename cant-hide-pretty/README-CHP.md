# Can't Hide Pretty — Storefront Redesign

Complete static storefront concept for Can't Hide Pretty Boutique, Panama City, Florida.

## Included
- Branded responsive home page
- Searchable catalog with category and mood filters
- Dynamic product detail page
- Persistent cart and wishlist using localStorage
- Our Story, Visit, FAQ, Contact, Policies and 404 pages
- Mobile navigation and responsive layouts
- Public product/brand imagery referenced from the boutique's storefront

## Production note
This is a front-end storefront prototype. Payments, inventory, live shipping rates, customer accounts and order processing still need to be connected to the boutique's Shopify backend before launch.
